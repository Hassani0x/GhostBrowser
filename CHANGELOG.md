# Changelog

## 0.3.1 — 2026-10-25

- Fixed screenshot clipboard writes using the asynchronous PNG clipboard API and awaiting completion.
- Added a Paste button and editable-field context-menu paste.
- Restored focus for screenshot paste workflows.
- Added production clipboard and controlled screen-to-clipboard pixel checks.

## 0.3.0 — 2026-10-25

- Added area screenshots from the desktop and other applications.
- Added a capture-protected selection overlay, global shortcut, and tray action.
- Added cancel, full-monitor capture, and display-scale-aware cropping.

## 0.2.0 — 2026-10-25

- Added per-website microphone prompts and session permission reset.
- Hid the browser's taskbar entry and added tray recovery controls.
- Reported pin-on-top failures when Windows refuses the request.

## 0.1.0 — 2026-10-25

- Initial Windows browser preview with capture exclusion, tabs, navigation, and sandboxed pages.
