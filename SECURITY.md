# Security

Please do not publish credentials, private screenshots, or exploit details in public issues. Use GitHub private vulnerability reporting if available. Otherwise, open an issue requesting a private contact channel without disclosing the vulnerability itself.

Gost sandboxes remote pages and limits app-control access. Microphone grants are origin-scoped and session-only. Screenshots are placed in the local clipboard without automatic upload; Windows clipboard history and sync may retain them. Website cookies persist in the local application profile.

Capture exclusion is a platform feature, not a confidentiality guarantee against every recording method. Verify the receiver's view before relying on it. System dialogs, shared audio, and the shared cursor are outside the protected browser surface.

The preview has no automatic updater. Check GitHub Releases for updates. Review any security fix and update manually.
